# 动作图解素材库规划（bryllim/workout-guide）

> 素材源：<https://github.com/bryllim/workout-guide> · 已核实（2026-09-02）
> 目标：把开源动作插画建成「素材库」，训练时按需显示动作画面，分两种模式（无画面/有画面）照顾老手与小白。

## 一、素材盘点（已核实）

| 项 | 值 |
| --- | --- |
| 动作数量 | **302 个** |
| 每动作素材 | **3 帧插画**（frame-1/2/3，可做成轮播动画） |
| 格式 | SVG + PNG 双份（512×512），SVG 单帧约 20KB |
| 元数据 | manifest.json：英文名、slug、器械、目标肌群、是否拉伸、帧路径、署名信息，全部结构化 |
| 器械分布 | 自重 111 / 哑铃 45 / 器械 35 / 杠铃 29 / 绳索 26 / 弹力带 19 … |
| 许可 | 代码 MIT；**插画 CC BY-SA 4.0**（可商用可修改，**必须署名**） |
| 分发 | npm 包 `@bryllim/workout-guide`（含 manifest + assets 导出） |

## 二、总体设计

### 1. 素材库（新增动作库数据层）
- 构建期脚本 `scripts/build-exercise-library.mjs`：拉取 manifest → 按「常用子集」筛选 → SVGO 压缩 SVG → 生成 `src/assets/exercises/<slug>/frame-{1,2,3}.svg` 与 `src/data/exerciseLibrary.ts`
- 数据结构：`{ slug, nameEn, nameZh, equipment, primaryMuscle, frames: [url1,url2,url3] }`
- **中文映射表**：常用动作手工映射（bench-press→卧推、squat→深蹲、deadlift→硬拉、pull-up→引体向上…约 80 条），未映射的显示英文原名——映射表独立文件，以后随时补
- 现有 `COMMON_EXERCISES` 常量与库对接：中文名 ↔ slug 双向可查

### 2. 体积策略（APK 现状 4MB，红线 +5MB）
- 只打 **SVG**（矢量、体积小、缩放无损），PNG 一律不打包
- 精选 **常用 80 动作** × 3 帧 × 20KB ≈ 4.8MB，SVGO 压缩后预计 **2.5~3MB**
- 全量 302 个（约 18MB）不进 APK——二期做「动作库在线按需拉取」再考虑

### 3. 两种模式（小白友好）
| | 模式1 极简（无画面） | 模式2 图解（有画面） |
|---|---|---|
| 训练进行页 | 只显示动作名（现状） | 动作名上方显示 **3 帧轮播动画**（600ms/帧循环），一眼看懂怎么做 |
| 排计划/加动作 | 文字 chips（现状） | 常用动作变**带缩略图的网格**，选动作像选表情 |
| 适合 | 老手，零干扰 | 小白，照着图做 |

- **切换开关**：训练进行页顶栏一个图解开关（即点即切，当次生效）+ 设置页「动作图解」总开关（持久化，默认**模式2 开**）
- 实现：一个 `ExerciseIllustration` 组件（props: slug，读库渲染 3 帧轮播），模式关闭时不渲染图片

### 4. 署名合规（CC BY-SA 硬要求）
- 设置页底部加：「动作插画 © Bryl Lim · CC BY-SA 4.0 · workout-guide」+ 原仓库链接
- ATTRIBUTION 复制进仓库 docs/

## 三、页面落点

1. **训练进行页**：当前动作的图解轮播（模式2 时），休息倒计时状态下也不消失——休息时正好看图学动作
2. **排计划**：常用动作选择从文字 chips 升级为「图 + 名」网格（模式2 时）
3. **训练 tab**：今日计划卡的动作名旁加小缩略图（可选，二期）
4. **设置页**：动作图解开关 + 署名信息

## 四、分期

| 期 | 内容 | 验收 |
| --- | --- | --- |
| 一期 | 构建脚本 + 精选 80 动作入库 + 中文映射 + ExerciseIllustration 组件 + 训练页轮播 + 两模式开关 + 署名 | APK 增量 ≤3MB；训练页开/关图解即时生效 |
| 二期 | 排计划带图网格、动作库浏览页（按器械/肌群筛选）、全量库按需在线拉取 | — |
