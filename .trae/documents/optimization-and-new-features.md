# 训练记录 App 优化与新功能计划

## 一、需要修复的问题

### 1. 日历月份同步 Bug（严重）
**问题**：`CalendarGrid` 内部用 `useCalendar()` 管理显示月份，但 `App.tsx` 用 `selectedDate` 计算的月份去获取 `trainingDates` 和 `tagsByDate`。当用户翻到其他月份但没选中某天时，训练标记和标签会显示错误。

**修复**：让 `CalendarGrid` 通过 `useCalendar` 的 year/month 去获取数据，或让 App.tsx 监听日历的实际显示月份。

### 2. 死代码清理
- `ExerciseForm.tsx` + `ExerciseForm.css` — 已无任何地方引用，可删除
- `types/index.ts` 中的 `TrainingType` 和 `TRAINING_TYPE_LABELS` — 已无引用
- `useTrainingStore` 导出的 `createExercise` — 外部无使用
- `TrainingRecord` 中的 `exercises`、`name`、`type`、`duration`、`note` 字段 — 表单和卡片都已不使用

### 3. 存储层潜在竞态条件
`storage.ts` 的 `deleteRecord` 是 load→modify→save，与 `saveRecords` 并发调用可能导致数据丢失。

## 二、优化项

### 4. 日历标签显示优化
- 当同一天有多条记录时，标签可能重复叠加（当前已去重，但同一天多条记录的标签会混在一起）
- 超过 2 个标签时只显示前 2 个，可以考虑加"+"号提示

### 5. 空状态优化
- 首次使用时没有引导提示
- 训练列表空状态文案可以更友好，引导用户点击"+"添加

### 6. 数据模型精简
既然表单和卡片只保留标签，可以大幅精简 `TrainingRecord`：
```typescript
interface TrainingRecord {
  id: string
  date: string
  tags: string[]
  createdAt: number
  updatedAt: number
}
```
删除 `name`、`type`、`duration`、`note`、`exercises` 等无用字段，减少存储空间。

## 三、可增加的功能

### 7. 标签管理页面
- 支持自定义预设标签（增删改默认的"推、拉、蹲"）
- 用 `@capacitor/preferences` 单独存储用户的预设标签列表
- 长按标签可以删除

### 8. 按标签筛选/统计
- 在首页添加标签筛选功能，点击某个标签只显示包含该标签的记录
- 添加月度标签统计视图（这个月推了多少天、拉了多少天）

### 9. 训练日历连续打卡
- 计算连续训练天数（连续打卡 streak）
- 在日历上方或标题区域显示当前连续天数
- 视觉上用连线/高亮标记连续打卡的日期

### 10. 历史记录回顾
- 添加一个简单的统计面板：本周/本月训练次数、最常使用的标签 Top 3
- 可以在首页顶部以小卡片形式展示

### 11. 长按日期快速添加
- 在日历上长按某天直接弹出标签选择面板（不需要进入完整表单页）
- 快速标记今天的训练，提升操作效率

### 12. 数据导出/备份
- 支持将训练记录导出为 JSON 文件
- 方便用户备份数据或迁移到其他设备
